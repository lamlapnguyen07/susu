怎麼下單

需要註冊會員嗎？

不用另外註冊。結帳時用 LINE 登入；第一次下單前，請先加入我們的 LINE 好友並輸入「登記」，留下姓名和電話。

萵苣「搭配包」和「指定品種」有什麼不同？

農場搭配包 NT${{ combo_price }}，由農場依當天採收混搭品種；指定品種每包 NT${{ pick_price }}，我們會盡量依你選的品種出貨，缺貨時會先用 LINE 跟你確認。每包約 400 公克。

一次可以買多少？

為了讓更多人買得到，每個 LINE 帳號每天最多訂 {{ daily_pack_limit }} 包萵苣；其他商品每樣每筆最多 {{ item_max_qty }} 件。

合作農場的商品可以和萵苣一起買嗎？

可以。全部放進同一台購物車、一次結帳，一起到取貨點拿。

取貨與付款

在哪裡取貨？

確認庫存後，我們會用 LINE 通知你取貨。取貨地點：{% for k, v in pickup_locations.items() %}{{ v.label | replace('　', ' ') }}{% if not loop.last %}、{% endif %}{% endfor %}。

怎麼付款？

下單不會先扣款。取貨時付現，或依 LINE 通知的方式轉帳。取貨時出示 LINE 收到的 QR Code 即可。

下單後可以取消嗎？

在「我的訂單」裡，還沒確認的訂單可以自己取消；已確認的訂單請用 LINE 聯絡我們。

保存

萵苣可以放多久？

連根的萵苣用袋子裝好放冰箱冷藏，大約可以放 7 到 10 天。

要洗嗎？

雖然沒有使用農藥，仍建議用清水沖洗後再吃。

注意事項

本農場採自然農法栽培，菜根可能附有微小生物，屬正常現象，食用前請清洗乾淨。各品項產量每週浮動，下單後若缺貨，我們會主動以 LINE 通知並提供替代方案。

退換貨

生鮮蔬菜屬於容易腐敗的商品，原則上不接受退貨。取貨時若發現嚴重蟲蛀、腐爛或品項錯誤，請在取貨當天透過 LINE 官方帳號回報並附上照片，我們會在下次出貨時補償或全額退款。

隱私權

為了處理訂單與通知，我們會在你用 LINE 登入或下單時，蒐集並儲存姓名、電話、LINE ID 與訂單紀錄。這些資料只用於訂單處理與 LINE 通知，不會提供給第三方。
